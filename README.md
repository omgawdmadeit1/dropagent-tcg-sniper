# DropAgent — TCG Restock Sniper

Multi-retailer TCG drop scanner with phone/browser alerts and simulated sniper agent.

## Run locally

```bash
npm install
npm run dev
```

## Stack

TanStack Start · React 19 · Vite · Tailwind v4 · Zustand

Demo only — stock checks and SMS are simulated; browser push notifications work on real devices when enabled.
